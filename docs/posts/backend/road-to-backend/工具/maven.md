# maven

maven是很常用的依赖管理的工具，便于我们导入依赖、导出jar包，快速构建工程

常见的命令有：

+ clean  清除target，也就是编译后的clss文件
+ complie 编译
+ install 导入pom文件所需要的依赖
+ package 打包成jar包到本地仓库

### 遇到的问题
maven 命令提示 'Error Running Jdk'，这需要检查maven插件的jdk配置
