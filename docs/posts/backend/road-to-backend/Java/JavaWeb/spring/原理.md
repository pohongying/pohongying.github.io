# 原理

## 核心
spring的核心是ioc(控制反转)和aop(面向切面编程)。

### IOC
它通过控制反转（IoC）容器，实现对象创建和管理的解耦，让开发者专注于业务逻辑，而非对象的创建和依赖关系的维护 。例如，以往需要在代码中手动 new 对象并处理依赖，使用 Spring IoC 后，对象由容器创建、装配和管理。

### AOP
它将横切关注点（如日志记录、事务管理等）从业务逻辑中分离出来，以增强代码的可维护性和可扩展性 。比如，在不修改业务方法代码的情况下，为其添加日志记录功能。
