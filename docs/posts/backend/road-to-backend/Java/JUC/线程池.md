# 线程池

### 通俗解释
参数：核心线程、最大线程、阻塞队列、超时时间、时间单位、拒绝策略

假设一个场景：

+ 厨师 - 核心线程
+ 最大员工数(10个厨师 )- 最大线程数
+ 临时工 - 救急线程
+ 订单栏 - 阻塞队列
+ 拒绝服务 - 拒绝策略

假如有3个厨师，永远不会被解雇，有订单看谁闲着就就干，没订单就等着。当都有活干的时候，将订单挂在订单栏上。如果订单栏也满了，但是厨师+临时工的数量小于最大员工数，则继续增加临时工，但是临时工是有聘用时间的，如果到时间了还没有活干，就直接开除了。最后所有人都有活干，订单还来的时候，只能告诉你店太忙了，明天再来吧！
