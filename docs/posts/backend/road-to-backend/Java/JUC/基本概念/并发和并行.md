# 并发和并行

并发是同一时间应对多件事情的能力，并行是同一时间动手做多件事的能力

举个例子，我通常在coding的时候唱歌，在这当中。并发就是：我不能真正的专注的听歌或者敲代码，但是大脑可以在这之间迅速的切换，比如我可能在敲代码的过程中，捕获到高潮部分的歌词。而并行，我可以耳朵听歌，手指在敲键盘，它们是可以实现并行的。

总的来说，<u>并发是 “统筹切换”，并行是 “同时执行”</u>
