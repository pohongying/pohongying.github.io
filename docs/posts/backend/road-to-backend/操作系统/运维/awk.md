# awk

`awk` 是一种强大的文本处理工具，在Linux系统中广泛用于对文本数据进行格式化处理、提取信息以及执行简单的计算等操作。以下是 `awk` 的基本用法及相关示例：

### 基本语法

```shell
awk [选项] '模式 {动作}' 文件
```

* **选项**：如 `-F` 用于指定字段分隔符。
* **模式**：用于匹配输入文本中的行，例如可以是正则表达式、关系表达式或者行号范围等。如果省略模式，则对每一行都执行动作。
* **动作**：是在匹配的行上执行的操作，通常是对行中的字段进行处理，多个动作之间用分号（`;`）分隔。

### 字段与记录

在 `awk` 中，输入文本被视为一系列的记录（通常一行就是一个记录），每个记录又被划分为若干字段。默认情况下，字段分隔符是空格或制表符。

### 常用示例

#### 1. 打印特定字段

假设存在一个文件 `data.txt`，内容如下：

```plain
Alice 25 Engineer
Bob 30 Doctor
Charlie 35 Teacher
```

要打印每行的第二个字段（年龄），可以使用：

```shell
awk '{print $2}' data.txt
```

这里 `$2` 表示第二个字段，`print` 是 `awk` 中用于输出的动作。

#### 2. 指定字段分隔符

如果文件中的字段分隔符不是默认的空格或制表符，比如是逗号，可以使用 `-F` 选项指定分隔符。例如，对于文件 `data.csv`：

```plain
Alice,25,Engineer
Bob,30,Doctor
Charlie,35,Teacher
```

使用如下命令打印每行的第一个字段：

```shell
awk -F, '{print $1}' data.csv
```

这里 `-F,` 将字段分隔符指定为逗号。

#### 3. 根据条件筛选并处理

只打印年龄大于30的人的信息：

```shell
awk '$2 > 30 {print $0}' data.txt
```

这里 `$2 > 30` 是模式，表示年龄大于30的行，`$0` 表示整行内容。

#### 4. 执行简单计算

计算文件中所有人的年龄总和：

```shell
awk '{sum += $2} END {print sum}' data.txt
```

这里 `sum += $2` 是动作，将每行的年龄累加到变量 `sum` 中。`END` 是一个特殊的模式，表示在处理完所有输入行后执行后面的动作，即打印年龄总和。

#### 5. 结合正则表达式

打印职业为 “Engineer” 的人的信息：

```shell
awk '/Engineer/ {print $0}' data.txt
```

这里 `/Engineer/` 是一个正则表达式模式，用于匹配包含 “Engineer” 的行。

#### 6. 使用自定义变量

可以定义并使用自定义变量。例如，给每个人的年龄加5：

```shell
awk -v increment=5 '{print $1, $2 + increment, $3}' data.txt
```

这里 `-v increment=5` 定义了一个名为 `increment` 的变量，并赋值为5，在动作中使用该变量对年龄进行计算。

`awk` 功能十分强大，通过灵活运用模式和动作，可以完成复杂的文本处理任务，在系统管理、数据处理和脚本编写等方面都有广泛应用。
