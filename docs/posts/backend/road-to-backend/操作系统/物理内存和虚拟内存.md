# 物理内存和虚拟内存

物理内存：内存，读取效率高

虚拟内存：硬盘，相当于对内存进行扩容，速度慢。

#### 如何转换的？
程序用的都是虚拟地址，认为自己的连续的。页表的每一项，基本单位是虚拟页（4kb，8kb)，记录两种对应关系

通过页表，记录对应关系（物理地址，通过MMU实时翻译地址。如果是物理内存直接找到，如果是虚拟内存则基本会发生缺页中断感觉读取到内存中）

#### 什么时候需要映射？
动态管理，按需加载。

发生缺页中断，硬盘上的虚拟地址到内存中，需要加载到内存，建立映射

内存不够用了，解除映射
