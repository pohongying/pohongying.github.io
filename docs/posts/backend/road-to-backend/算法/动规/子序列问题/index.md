# 子序列问题

单序列DP或者双序列DP

***

### 模板一：单序列DP (一维`dp`数组)

这种模板的核心是 `dp[i]` 的定义与 **“结尾”** 相关，通常用于解决单个数组/字符串的子序列问题。

#### **核心思想**

`dp[i]` 代表**必须以 **`**nums[i]**`** 这个元素结尾**的子序列，其满足题意的属性值（如长度、和等）。

#### **模板精简**

1. **定义 **`**dp**`** 数组**: `dp[i]` 表示以 `nums[i]`**结尾**的最优解。

**状态转移**: 遍历 `j` 从 `0` 到 `i-1`，通过 `nums[i]` 与 `nums[j]` 的关系，更新 `dp[i]`。

2. Java

```plain
// 伪代码
for (int i = 0; i < n; i++) {
    // 每个dp[i]都有一个初始值
    dp[i] = ...; 
    for (int j = 0; j < i; j++) {
        if (nums[i] 和 nums[j] 满足某种条件) {
            dp[i] = Math.max(dp[i], dp[j] + ...);
        }
    }
}
```

3. **最终结果**: **不一定是 **`**dp[n-1]**`，因为最优子序列可能在任何位置结尾。需要遍历整个 `dp` 数组找最大值。

#### **典型例题**

* **最长递增子序列 (LIS)**
  * `dp[i]`：以 `nums[i]` 结尾的最长递增子序列的**长度**。
  * 转移：如果 `nums[i] > nums[j]`，则 `dp[i] = max(dp[i], dp[j] + 1)`。
  * 结果：`max(dp[0]...dp[n-1])`。
* **最大子数组和** (虽然是子数组，但思想一致)
  * `dp[i]`：以 `nums[i]` 结尾的最大子数组**和**。
  * 转移：`dp[i] = max(nums[i], dp[i-1] + nums[i])`。
  * 结果：`max(dp[0]...dp[n-1])`。

***

### 模板二：双序列/区间DP (二维`dp`数组)

这种模板的核心是 `dp[i][j]` 的定义与\*\*“前缀”或“区间”\*\*相关，通常用于两个序列的对比，或单个序列的子串问题。

#### **核心思想**

`dp[i][j]` 代表 **序列一的前 **`**i**`** 个元素** 和 **序列二的前 **`**j**`** 个元素** 之间的关系，或者 **单个序列的 **`**[i...j]**`** 区间** 的解。

#### **模板精简**

1. **定义 **`**dp**`** 数组**:
   * **双序列**：`dp[i][j]` 表示 `text1` 的前 `i` 个字符与 `text2` 的前 `j` 个字符的解。(推荐数组大小 `[n+1][m+1]`)
   * **单序列区间**：`dp[i][j]` 表示 `s` 在 `[i...j]` 区间上的解。
2. **状态转移**: 核心是判断**两个端点**`s1[i-1]` 和 `s2[j-1]` (或 `s[i]` 和 `s[j]`) 的关系。

Java

```plain
// 伪代码 (双序列)
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (s1[i-1] == s2[j-1]) {
            // 端点相同，通常状态来自左上角
            dp[i][j] = dp[i-1][j-1] + ...;
        } else {
            // 端点不同，通常状态来自左边或上边
            dp[i][j] = max/min(dp[i-1][j], dp[i][j-1], ...);
        }
    }
}
```

3. **最终结果**:
   * **双序列**：通常是 `dp[n][m]`。
   * **单序列区间**：通常是 `dp[0][n-1]`。

#### **典型例题**

* **最长公共子序列 (LCS)**
  * `dp[i][j]`：`text1[0..i-1]` 和 `text2[0..j-1]` 的最长公共子序列**长度**。
  * 转移：若 `text1[i-1] == text2[j-1]`，则 `dp[i][j] = dp[i-1][j-1] + 1`；否则 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`。
  * 结果：`dp[n][m]`。
* **最长回文子序列**
  * `dp[i][j]`：字符串 `s` 的 `[i...j]` 区间内最长回文子序列的**长度**。
  * 转移：若 `s[i] == s[j]`，则 `dp[i][j] = dp[i+1][j-1] + 2`；否则 `dp[i][j] = max(dp[i+1][j], dp[i][j-1])`。
  * 结果：`dp[0][n-1]`。

***

### **总结重点 (Key Takeaway)**

| 模板类型 | `dp`<br> 数组定义 | 最终结果位置 | 核心 |
| --- | --- | --- | --- |
| **模板一 (1D)** | 以 `nums[i]`<br>**结尾**的最优解 | `max(dp)` | **局部最优** -> **全局最优** |
| **模板二 (2D)** | **前缀**`[0..i]`<br> 与 `[0..j]`<br> 或 **区间**`[i..j]`<br> 的解 | `dp[n][m]`<br> 或 `dp[0][n-1]` | **子问题** -> **原问题** |
