# 回文子串-中心扩散

### 中心扩展法核心原理

回文串具有中心对称性，其中心可能是一个字符（如 "aba" 的中心是 'b'），也可能是两个字符（如 "abba" 的中心是 "bb"）。

遍历字符串中的每个字符，将其作为回文串的中心，或者将其与下一个字符一起作为中心

向两边扩展，以找出以该中心为基准的最长回文子串。

最后，比较所有找到的回文子串，找出最长的那个。

### 代码

```java
class Solution {
    public String longestPalindrome(String s) {
        String res = "";
        for(int i=0;i<s.length();i++){
            String str1 =  palindrome(s,i,i);
            String str2 =  palindrome(s,i,i+1);
            res = res.length() > str1.length() ? res : str1;
            res = res.length() > str2.length() ? res : str2;
        }
        return res;
        
    }

    public String palindrome(String s,int l,int r){

        while(l>=0 && r < s.length() && 
            s.charAt(l) == s.charAt(r)
         ){
            l--;
            r++;
         }
         return s.substring(l+1,r);
    }
}
```

### 中心点是什么？

一个字符串的中心点有两种情况：

* **单个字符做中心**：比如 `a`、`b`、`a` 在 `"aba"` 中，都可以是中心。从这个单字符开始，左右指针同时向两边移动。
* **两个相邻的相同字符做中心**：比如 `b`、`b` 在 `"abba"` 中，可以共同组成一个中心。从这两个字符开始，左右指针再向两边移动。

### 为什么中心不能是三个字符

因为任何一个长度为 3 的回文串（如 `aba`），它本身就可以由最中间的那个单字符（`b`）作为中心点扩展一次得到。同理，更长的奇数长度回文串也是如此。偶数长度的回文串（如 `abba`）可以由最中间的两个字符（`bb`）作为中心点扩展得到。所以，只需要考虑 单个字符 和 两个相邻字符 这两种中心就足够了。

### 为什么有 2\*n -1 个中心点？

这正好对应了上面两种情况：

* `n`\*\* 个单字符中心\*\*：字符串中的每个字符都可以是一个中心点。
* `n - 1`\*\* 个双字符中心\*\*：每两个相邻的字符之间，都可以看作一个潜在的中心点。

所以总的中心点数量就是 `n + (n - 1) = 2n - 1` 个。

***

### 总结

算法的执行流程就是：

1. 写一个循环，遍历这 `2 * n - 1` 个中心点。
2. 对于每一个中心点，用两个指针（`left` 和 `right`）从中心开始，不断地向两边扩展。
3. 在扩展的过程中，只要左右两边的字符相等，就继续扩展，并记录下当前找到的回文串。
4. 如果左右字符不相等，或者指针越界了，就停止对当前中心点的扩展。
5. 遍历完所有中心点后，记录下的最长的那个回文串就是最终答案。

这个方法之所以巧妙，是因为它避开了复杂的动态规划状态转移，用一种非常直观的“两边扩展”的方式，暴力且高效地找到了所有可能的回文串。
