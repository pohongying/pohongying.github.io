# dp界限问题

***

### 第一步：定义 `dp[i]` 的含义 (核心！)

这是最关键的一步，它直接决定了后面的一切。对于一个长度为 `n` 的输入数组 `nums`，通常有两种定义 `dp` 数组含义的方式：

* **方式一（最常见，推荐）：**`dp[i]`\*\* 表示考虑\*\*前 `i` 个元素 (`nums[0]` 到 `nums[i-1]`) 时，得到的结果。
* **方式二（特定问题用）：**`dp[i]`\*\* 表示\*\*必须包含 `nums[i]` 这个元素时，得到的结果。

这两种定义会直接导致后面两步的巨大差异。我们分别来看。

***

### 方式一：`dp[i]` 定义为“前 `i` 个元素”的结果 (区间)

这种定义方式通常用于解决“子序列”、“子数组和”、“背包问题”等。

#### 1. 数组大小 (`dp` Size)

* **大小**：通常是 `n + 1`。
* **原因**：`dp[0]` 有了明确的含义——代表\*\*“前 0 个元素”\*\*，也就是一个空集或空字符串。这个 `dp[0]` 就是我们处理所有边界情况的“虚拟起点”或“哨兵”，它能极大简化代码逻辑。
* **对应关系**：
  * `dp[0]` -> 空集
  * `dp[1]` -> 考虑 `nums[0]`
  * `dp[i]` -> 考虑 `nums[0]` 到 `nums[i-1]`
  * `dp[n]` -> 考虑 `nums[0]` 到 `nums[n-1]` (整个数组)

#### 2. 边界初始化 (Base Case)

* **初始化谁**：通常是 `dp[0]`。
* **如何初始化**：思考 `dp[0]` 的含义——“对于一个空集，我们要求解的问题的答案是什么？”
  * **例1：求最长公共子序列**。空字符串和任何字符串的公共子序列长度都是 0，所以 `dp[0][j] = 0`, `dp[i][0] = 0`。
  * **例2：爬楼梯** (`dp[i]` 表示爬到第 `i` 阶的方法数)。`dp[0]` 可以理解为“原地不动”，算 1 种方法。`dp[1]` 是 1 种方法。
  * **例3：0-1背包问题** (`dp[j]` 表示容量为 `j` 的背包能装的最大价值)。`dp[0]` 表示容量为 0 的背包，价值当然是 0。

#### 3. 最终结果 (Return Value)

* **返回谁**：通常是 `dp[n]`。
* **原因**：根据我们的定义，`dp[n]` 的含义是**考虑“前 n 个元素” (**`nums[0...n-1]`**)**，也就是整个输入数组，所得到的结果。这自然就是题目的最终答案。

***

### 方式二：`dp[i]` 定义为“必须包含 `nums[i]`”的结果 (端点)

这种定义方式通常用于解决“最大子数组和”、“最长递增子序列”这类问题，问题的解可能出现在中间任何位置。

#### 1. 数组大小 (`dp` Size)

* **大小**：通常是 `n`。
* **原因**：`dp[i]` 和 `nums[i]` 是一一对应的。`dp[0]` 就对应 `nums[0]` 的情况，`dp[i]` 对应 `nums[i]` 的情况。我们不需要一个额外的“空集”状态，所以大小为 `n` 就足够了。
* **对应关系**：
  * `dp[0]` -> 必须包含 `nums[0]` 的结果
  * `dp[i]` -> 必须包含 `nums[i]` 的结果

#### 2. 边界初始化 (Base Case)

* **初始化谁**：通常是 `dp[0]`。
* **如何初始化**：思考 `dp[0]` 的含义——“当只考虑 `nums[0]` 并且必须包含它时，结果是什么？” 答案通常就是 `nums[0]` 本身。
  * **例1：最大子数组和**。`dp[0]` 表示必须以 `nums[0]` 结尾的最大子数组和，那自然就是 `nums[0]`。
  * **例2：最长递增子序列**。`dp[0]` 表示必须以 `nums[0]` 结尾的最长递增子序列的长度，那长度就是 1 (只有它自己)。

#### 3. 最终结果 (Return Value)

* **返回谁**：**不一定是 **`dp[n-1]`**！** 而是 `dp` 数组中的**最大值**。
* **原因**：根据我们的定义，`dp[i]` 只是以 `nums[i]` \_结尾\_的局部最优解。而全局最优解（整个数组的最大子数组和、最长递增子序列）可能在任何一个 `i` 的位置结束。因此，我们需要遍历整个 `dp` 数组，找到那个最大的值，它才是全局最优解。

```java
int result = dp[0];
for (int i = 1; i < n; i++) {
    result = Math.max(result, dp[i]);
}
return result;
```

***

### 总结与对比

| 特性 | **方式一 (区间定义)** | **方式二 (端点定义)** |
| :--- | :--- | :--- |
| `dp[i]`\*\* 含义\*\* | 考虑**前 **`i`** 个元素** (`nums[0...i-1]`) 的结果 | 考虑以 `nums[i]` **结尾**的结果 |
| **适用问题** | 背包、公共子序列、路径总数 | 最大子数组和、最长递增子序列 |
| **数组大小** | `n + 1` | `n` |
| **Base Case** | 初始化 `dp[0]` (空集状态) | 初始化 `dp[0]` (单个元素 `nums[0]` 的状态) |
| **最终结果** | `dp[n]` | `max(dp[0], dp[1], ..., dp[n-1])` |

### 实战建议

1. **先问自己**：这道题的最终答案，是与整个输入有关（例如整个字符串的最长子序列），还是可能在输入的某个中间部分就产生了（例如最大和的子数组可能只在数组中间）？
   * 前者倾向于**方式一**。
   * 后者倾向于**方式二**。
2. **明确写下 **`dp[i]`** 的定义**：在写代码前，用注释写下 `// dp[i] 表示 ...`。这是保证你后续步骤不出错的“锚”。
3. **根据定义推导**：
   * 定义定了，大小就定了。
   * 定义定了，Base Case 就定了。
   * 定义定了，最终返回什么也就定了。

希望这个“三步决策法”和两种模式的对比，能帮你彻底理清 `dp` 数组的边界和结果问题！多练习几道题，套用这个思路，很快就能形成肌肉记忆。
