# 动规

## 什么是动规？
动规就是动态转移方程，本质上是暴力枚举的优化手段。它可以由递归推出，和有记忆的递归很像。

动态规划是一种优化过后的穷举，意思是本质就是穷举，不同于递归自顶向下，它是自顶向上的。动态规划可以把O(n2)的时间复杂度变为O(n)。

动态规划能优化的穷举是有条件的，要解决的这个问题，你得能转换成子问题去解决，一般来说是解决最值问题，因为求最值就需要穷举，但是不同于一般的穷举，它是有很多重复的结构。

经典例子——斐波那契数列

1. 暴力递归。F(n) = f(n-1) + f(n-2)
2. 带备忘录的递归。就是递归的时候，把当前的值用哈希存储起来，遇到记录的就不需要再一一的递归了，加快了效率。这种方法和动规已经很像了，不过是自顶向下。
3. 动规。动规又可以进行状态压缩

这里面最重要的就是状态转移方程，也可以叫递推公式，这三种只是表现形式不同而已。

## 什么时候用动规？
这个很关键，看到题如何判断这个题就是动规呢。

一般来说有三点需要注意的：最优子结构、重复问题、独立

1. **最优解问题**：求最大值（如最大利润、最长子序列）、最小值（如最短路径、最小成本）。
2. **计数问题**：求方案数（如不同路径数、解码方式数）。
3. **存在性问题**：判断是否有可行方案（如能否分割为等和子集）。
