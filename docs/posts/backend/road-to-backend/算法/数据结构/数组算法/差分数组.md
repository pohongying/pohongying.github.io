# 差分数组

### 定义
适用于区间修改，前缀和是相加，差分是相邻元素的相减，因此差分是可以转换回去的。为什么差分可以便于修改呢，其实就是数字游戏，一个相加，一个相减即可，因为差分的大小可以看作是递减的，因此遍历的时候，后面也可以用到

### 模板
```java
class Difference {
    private int[] diff;

    public Difference(int[] nums) {
        int n = nums.length;
        diff = new int[n + 1];
        for (int i = 1; i < n + 1; i++) {
            diff[i] = diff[i - 1] - nums[i - 1];
        }
    }

    public void increment(int i, int j, int val) {
        diff[i] += val;
        if (j + 1 < diff.length) {
            diff[j] -= val;
        }
    }

    public int[] result() {
        int[] res = new int[diff.length];
        // 根据差分数组构造结果数组
        res[0] = diff[0];
        for (int i = 1; i < diff.length; i++) {
            res[i] = res[i - 1] + diff[i];
        }
        return res;
    }
}
```
