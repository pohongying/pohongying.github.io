# 二分查找

### 什么是二分查找？

二分查找首先是个查找，得有个target目标数，如何找呢，每次都会根据左右边界，来计算出中间节点的值，去和目标值进行比较，根据大小去移动左右边界。

使用场景，像查找某个数、查找某个数的平方数、平方根等

### 使用条件

有序、有个目标数

### 注意的点

要保证循环不变量，左闭右闭、左闭右开、左开右开等，你每次判断的时候，都得遵循这个规则，哟啊不然很容易出问题。

有三个值需要注意left 、right、mid

一般来说，left是找到的第一个数的索引(如果有多个的话），或者是要插入的位置。什么意思，就是left不管是找的数有还是没有，有的话就是第一个数，没有的话就是要插入的数。

## 区间

> 峰值闭区间注意right = n-2，因为肯定有一个峰值

```java
public int left_bound(int[] nums, int target) {
    if(nums.length==0){
        return -1;
    }
  
    int left = 0, right = nums.length - 1;
    if (target < nums[left] || target > nums[right]) {
        return -1;
    }
    // [left,right]
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] > target) {
            right = mid - 1;
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else if (nums[mid] == target) {
            right = mid - 1;
        }
    }
    return nums[left] == target ? left : -1;
}

public int right_bound(int[] nums, int target) {
    if(nums.length==0){
        return -1;
    }
  
    int left = 0, right = nums.length - 1;
    if (target < nums[left] || target > nums[right]) {
        return -1;
    }
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] > target) {
            right = mid - 1;
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else if (nums[mid] == target) {
            left = mid + 1;
        }
    }
    return nums[right] == target ? right : -1;
}
```

## 泛化问题

首先，你要从题目中抽象出一个自变量 `x`，一个关于 `x` 的函数 `f(x)`，以及一个目标值 `target`。

同时，`x, f(x), target` 还要满足以下条件：

1、`f(x)` 必须是在 `x` 上的单调函数（单调增单调减都可以）。

2、题目是让你计算满足约束条件 `f(x) == target` 时的 `x` 的值。

一个变量关联了另外一个，然后必须要有单调性，区间搜索
