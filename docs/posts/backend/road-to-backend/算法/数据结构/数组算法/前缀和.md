# 前缀和

### 定义：

前缀和技巧适用于快速、频繁地计算一个索引区间内的元素之和，常常和hashmap结合起来

关键字：子数组、区间

公式：元素和 = preSum\[right+1] - preSum\[left]。

### 模板

```java
class NumArray {
    // 前缀和数组
    private int[] preSum;

    // 输入一个数组，构造前缀和
    public NumArray(int[] nums) {
        // preSum[0] = 0，便于计算累加和
        preSum = new int[nums.length + 1];
        // 计算 nums 的累加和
        for (int i = 1; i <=n ; i++) {
            preSum[i] = preSum[i - 1] + nums[i - 1];
        }
    }

    // 查询闭区间 [left, right] 的累加和
    public int sumRange(int left, int right) {
        return preSum[right + 1] - preSum[left];
    }
}
```

### 注意事项：

* 第一个局限性：使用前缀和技巧的前提是原数组 `nums` 不会发生变化。
* 第二个局限性：前缀和技巧只适用于存在逆运算的场景。

### 延伸：

* 前缀乘积，从1开始，不用从n+1，因为不需要相减
* 前后缀，适用于找出前后相等

```java
class Solution {
    public int trap(int[] height) {
        // 前后缀最大值
        int n = height.length;
        int[] preMax = new int[n];
        preMax[0] = height[0];
        for (int i = 1; i < n; i++) {
            preMax[i] = Math.max(preMax[i - 1], height[i]);
        }
        int[] suffixMax = new int[n];
        suffixMax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            suffixMax[i] = Math.max(suffixMax[i + 1], height[i]);
        }

        int res = 0;
        for (int i = 0; i < n; i++) {
            res += Math.min(preMax[i], suffixMax[i]) - height[i];
        }
        return res;

    }

}
```

### 题型

> 原理：子数组和 = preSum\[j] - preSum\[i] = need

* 一维数组区域求和，二维数组范围求和
* 子数组和。hashmap的值可以为索引值i，次数count

和hashmap的题型，一般可以在求preSum 的时候同时计算了，现判断满足条件的need存不存在，如果存在则说明找到了。同时把当前的数加进来，可能是加的索引(长度最大，索引一般是越小越好)，或者次数

整除 -->取余

又明显分界线  --> 归一化处理

#### 代码

> 只有0会重复出现
>
> 通过i - 上一个索引位置，来实现区间获取

```java
class Solution {
    public int findMaxLength(int[] nums) {
        int n = nums.length;
        int[] preSum = new int[n + 1];
        preSum[0] = 0;
        // 计算 nums 的前缀和
        for (int i = 0; i < n; i++) {
            preSum[i + 1] = preSum[i] + (nums[i] == 0 ? -1 : 1);
        }
        // 前缀和到索引的映射，方便快速查找所需的前缀和
        HashMap<Integer, Integer> valToIndex = new HashMap<>();
        int res = 0;
        for (int i = 0; i < preSum.length; i++) {
            // 如果这个前缀和还没有对应的索引，说明这个前缀和第一次出现，记录下来
            // 只有0会重复出现
            if (!valToIndex.containsKey(preSum[i])) {
                valToIndex.put(preSum[i], i);
            } else {
                // 这个前缀和已经出现过了，则找到一个和为 0 的子数组
                
                res = Math.max(res, i - valToIndex.get(preSum[i]));
            }
            // 因为题目想找长度最大的子数组，所以前缀和索引应尽可能小
        }
        return res;
    }
}
```

class Solution {
    public int subarraySum(int[] nums, int k) {
        int n = nums.length;
        int[] preSum = new int[n + 1];
        preSum[0] = 0;
        for (int i = 1; i <= n; i++) {
            preSum[i] = preSum[i - 1] + nums[i - 1];
        }
        // value为数组的个数，不是索引值
        // 原理：presum[j] - preSum[i]
        Map<Integer, Integer> map = new HashMap<>();
        int res = 0;
        map.put(0,1);  // 确保恰好的
        for (int i = 1; i <= n; i++) { // 遍历前缀和数组
            int need = preSum[i] - k;
            if (map.containsKey(need)) {
                res += map.get(need);
            }
            if (!map.containsKey(preSum[i])) {
                map.put(preSum[i], 1);
            } else {
                map.put(preSum[i], map.get(preSum[i]) + 1);
            }
        }
        return res;
    }
}
