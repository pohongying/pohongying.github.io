# 二分判断算法

### 场景
用于多对多关系中，需要边的两点不能为一组(需要是不同的颜色）

### 代码模版
```java
class Solution {
    boolean[] visited;
    boolean[] color;
    boolean ok = true; // 是否符合二分图的性质

    public boolean isBipartite(int[][] graph) {
        int n = graph.length; //节点数

        visited = new boolean[n];
        color = new boolean[n];

        // 遍历节点
        for (int v = 0; v < n; v++) {
            if (!visited[v]) {
                traversal(graph, v);
            }
        }
        return ok;

    }

    public void traversal(int[][] graph, int v) {

        if (!ok) {
            return;
        }
        visited[v] = true;
        for (int w : graph[v]) { //遍历临接
            if (!visited[w]) {
                // 涂上不同颜色
                color[w] = !color[v];
                traversal(graph, w);
            } else {
                if (color[v] == color[w]) {
                    ok = false;
                }
            }
        }
    }
}
```
