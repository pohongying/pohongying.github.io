# 括号类问题

有效括号问题，就是一个左，一个右，一一对应。意思就是，先把左的压入栈，如果遇到右的了，我再来比较。

括号的最少操作数，思路就是分别计算左、右括号的数目，如果右括号数目少了，就得补充左括号数。
