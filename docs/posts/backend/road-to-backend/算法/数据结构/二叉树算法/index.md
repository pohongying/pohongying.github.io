# 二叉树算法

二叉树实际上讲的主要是递归和BFS。递归的思维分为两种，一种是递归式(从下往上），直接返回值，另一种是遍历式(从上往下)，需要借助全局变量。实际上对应的遍历方式后序或者前序。

返回值一般用于递归的思想，还可以用来根据转态，来选择返回
