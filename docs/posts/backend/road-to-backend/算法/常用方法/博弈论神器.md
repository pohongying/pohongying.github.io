# 博弈论神器

***

### **博弈论神器：SG 函数技术笔记**

#### **一句话总结**

SG 函数是用来解决“公平组合游戏”的通用必杀技。它巧妙地**把所有复杂的游戏状态“数字化”**，然后通过一个简单的**异或（XOR）运算**，就能直接告诉你当前局面是必胜还是必败。

***

#### **1. 它能解决什么问题？(应用场景)**

SG 函数专门解决一类叫做 **“公平组合游戏”（Impartial Games）** 的问题。要使用 SG 函数，游戏必须满足以下特点：

* **两人轮流**：两位玩家交替行动。
* **信息公开**：没有隐藏信息，比如手牌。
* **无运气成分**：没有骰子、抽卡等随机事件。
* **动作与玩家无关**：在任何局面下，轮到谁，他能做的操作都完全一样。（这是“公平”的核心，象棋里你不能动对方的子，所以不是公平游戏）。
* **游戏会结束**：不能无限玩下去。
* **无法操作者输**：谁最后没法动了，谁就输了。

**典型例子**：

* ✅ **各种取石子游戏（尼姆游戏 Nim Game）**
* ✅ **图上移动棋子游戏**
* ❌ **象棋、围棋、扑克牌、石头剪刀布** (因为操作跟玩家有关或有运气成分)

***

#### **2. 核心思想**

SG 理论的核心思想分为两部分：为单个游戏“打分”，以及将多个游戏“合并”。

##### **Part 1：给状态“打分” —— SG 值**

我们可以给游戏中的**每一种局面**（状态）计算一个“分数”，这个分数就是 **SG 值**，它是一个非负整数。

* **SG 值 = 0**：代表这个局面是 **“坏”** 的，谁轮到这个局面谁就**必败**（P-position，Previous Player Win）。
* **SG 值 ****>**** 0**：代表这个局面是 **“好”** 的，谁轮到这个局面谁就**必胜**（N-position，Next Player Win）。

**怎么算这个分数？**
靠一个叫 `mex` (Minimum Excluded value) 的操作，意思是“**找没出现过的最小非负整数**”。

* `mex({0, 1, 3}) = 2` （因为 2 是第一个没在集合里出现的）
* `mex({1, 2, 3}) = 0` （因为 0 是第一个没在集合里出现的）

**SG 值的计算公式：**

> **一个局面的 SG 值 = mex( 它所有下一步能到达的局面的 SG 值集合 )**

**通俗理解**：我想知道我现在的局面好不好，就去看我走一步之后，能把对手送到哪些局面。把那些局面的“分数”都收集起来，然后找一个他们**都没拿到过的最小分数**，就是我当前局面的分数。
特别是，如果我能把对手送到一个 `SG = 0` 的“坏”局面，那我的局面一定是“好”的 (`SG > 0`)。

##### **Part 2：给游戏“合并” —— 异或和 (XOR)**

这是 SG 理论最强大的地方。如果一个游戏是由好几个**独立的子游戏**构成的（比如有好几堆石子，每次只能动一堆），我们不需要考虑复杂的整体局面。

**合并规则：**

> **总局面的 SG 值 = 所有子游戏的 SG 值 的 异或和 (XOR)**

**XOR** 就是编程语言里的 `^` 运算符。
例如，有三堆石子（三个子游戏），它们的 SG 值分别是 3, 5, 7。
那么整个局面的总 SG 值就是 `3 ^ 5 ^ 7 = 1`。

***

#### **3. 实战五步法**

拿到一个博弈问题，可以按以下步骤操作：

1. **识别**：判断这是不是一个“公平组合游戏”。
2. **拆分**：把整个游戏局面拆分成多个独立的子游戏。
3. **计算**：分析单个子游戏，找出计算它 SG 值的规律或公式。（这是最难的一步，通常需要递推、动态规划或找数学规律）
4. **合并**：用异或 `^` 运算，把所有子游戏的 SG 值加起来，得到总 SG 值。
5. **判断**：
   * 如果总 SG 值 **不等于 0**，则先手**必胜**。
   * 如果总 SG 值 **等于 0**，则先手**必败**。

***

#### \*\*4. 经典例子：尼姆游戏 \*\*`[1, 2, 3]`

有三堆石子，数量分别为 1, 2, 3。

1. **识别**：是公平组合游戏。
2. **拆分**：分为三堆石子，`[1]`, `[2]`, `[3]`，是三个独立的子游戏。
3. **计算**：对于单堆石子的尼姆游戏，可以证明，有 `k` 个石子的堆，其 `SG(k) = k`。
   * `SG(1) = 1`
   * `SG(2) = 2`
   * `SG(3) = 3`
4. **合并**：计算异或和 `1 ^ 2 ^ 3`
   * `1` (二进制 `01`) `^ 2` (二进制 `10`) `= 3` (二进制 `11`)
   * `3` (二进制 `11`) `^ 3` (二进制 `11`) `= 0` (二进制 `00`)
5. **判断**：总 SG 值为 0，所以这是一个**先手必败**的局面。

***

#### **5. 关键代码模板**

计算单个子游戏的 SG 值，最通用的方法是“递归 + 记忆化搜索”。

```java
// !!! 警告：这是一个理论上的模板，对于本题会因为 a 的值太大而超时 !!!
// !!! 仅用于理解 SG 函数的递归定义 !!!

Map<Integer, Integer> memo = new HashMap<>(); // 用于记忆化

int calculateSgRecursive(int a) {
    if (a <= 1) { // 规则规定 a > 1 才能操作，所以 a=1 是终止态
        return 0;
    }
    if (memo.containsKey(a)) {
        return memo.get(a);
    }

    Set<Integer> nextSgValues = new HashSet<>();
    
    // 遍历所有可能的下一步操作
    // 规则：移走 d*s 个石子，d为奇数, s>=1
    // 这会导致非常多的后继状态，这里仅为示意
    for (int s = 1; s <= a; s++) {
        for (int d = 1; d * s <= a; d += 2) { // d是奇数
            int remainingStones = a - d * s;
            nextSgValues.add(calculateSgRecursive(remainingStones));
        }
    }
    
    // 计算 mex
    int mex = 0;
    while (nextSgValues.contains(mex)) {
        mex++;
    }
    
    memo.put(a, mex);
    return mex;
}
```

#### **总结与要点**

* **看到公平博弈，想到 SG 函数**。
* **单个局面好不好，看 SG 值** (`SG=0` 必败)。
* **SG 值怎么算，靠 mex** (找最小的空缺)。
* **组合游戏怎么办，靠异或** (`^`)。
* **最难的部分**：通常是分析单个子游戏，找到 `SG(k)` 的规律，从而避免暴力递归。
