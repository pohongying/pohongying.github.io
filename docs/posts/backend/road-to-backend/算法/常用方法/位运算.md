# 位运算

### **一、基础位操作**

1. **设置第**`k`**位为1**
   **公式**: `n | (1 << k)`
   **示例**:
   `n = 0b1010` (10), `k = 1` → `0b1010 | 0b0010 = 0b1110` (14)
2. **清除第**`k`**位为0**
   **公式**: `n & ~(1 << k)`
   **示例**:
   `n = 0b1110` (14), `k = 1` → `0b1110 & 0b1101 = 0b1100` (12)
3. **切换第**`k`**位（取反）**
   **公式**: `n ^ (1 << k)`
   **示例**:
   `n = 0b1010` (10), `k = 1` → `0b1010 ^ 0b0010 = 0b1000` (8)

***

### **二、数学性质**

4. **清除最低位的1**
   **公式**: `n & (n - 1)`
   **示例**:
   `n = 0b1010` (10) → `0b1010 & 0b1001 = 0b1000` (8)
5. **保留最低位的1**
   **公式**: `n & (-n)`
   **示例**:
   `n = 0b1010` (10) → `-n`（补码）= `0b0110`（假设4位）→ `0b1010 & 0b0110 = 0b0010` (2)
6. **判断是否是2的幂**
   **公式**: `(n > 0) && (n & (n - 1) == 0)`
   **示例**:
   `n = 0b1000` (8) → `0b1000 & 0b0111 = 0` ✔️
   `n = 0b1010` (10) → `0b1010 & 0b1001 = 0b1000` ≠ 0 ❌

***

### **三、位移操作**

7. **取第**`k`**位的值**
   **公式**: `(n >> k) & 1`
   **示例**:
   `n = 0b1010` (10), `k = 3` → `0b1010 >> 3 = 0b0001` → `0b0001 & 1 = 1`
8. **快速乘/除以2的幂**
   **公式**:
   * 乘 `2^k`: `n << k`
   * 除 `2^k`: `n >> k`
     **示例**:
     `n = 0b1010` (10), `k = 2` → `0b1010 << 2 = 0b101000` (40)
     `n = 0b1010` (10), `k = 1` → `0b1010 >> 1 = 0b0101` (5)

***

### **四、异或（XOR）性质**

9. **交换变量**
   **公式**:

```plain
a ^= b  
b ^= a  
a ^= b  
```

**示例**:
`a = 0b101` (5), `b = 0b011` (3) → 交换后 `a=0b011`, `b=0b101`

10. **相同数异或归零**
    **公式**: `n ^ n = 0`
    **示例**:
    `0b1101 ^ 0b1101 = 0b0000`
11. **异或的逆运算是自身**
    **公式**: `(a ^ b) ^ b = a`
    **示例**:
    `a = 0b101`, `b = 0b011` → `0b101 ^ 0b011 = 0b110` → `0b110 ^ 0b011 = 0b101`

***

### **五、位掩码与状态**

12. **生成低**`k`**位全1的掩码**
    **公式**: `mask = (1 << k) - 1`
    **示例**:
    `k = 3` → `mask = 0b1000 - 1 = 0b0111`
13. **提取高**`k`**位的值**
    **公式**: `(n >> (总位数 - k)) & ((1 << k) - 1)`
    **示例**（8位数）:
    `n = 0b11011010`, `k = 4` → 右移4位 → `0b1101` & `0b1111` = `0b1101`

***

### **六、特殊技巧**

14. **快速判断奇偶性**
    **公式**: `n & 1`
    **示例**:
    `n = 0b1010` → `0b1010 & 1 = 0`（偶数）
    `n = 0b1011` → `0b1011 & 1 = 1`（奇数）
15. **二进制反转（4位示例）**
    **公式**（分治法）:

```plain
n = ((n >> 1) & 0x5) | ((n & 0x5) << 1)  // 交换每1位  
n = ((n >> 2) & 0x3) | ((n & 0x3) << 2)  // 交换每2位  
```

**示例**:
`n = 0b1101` → 反转后 `0b1011`

***

### **七、补码与负数**

16. **求补码（负数）**
    **公式**: `~n + 1`
    **示例**（4位）:
    `n = 0b0010` (2) → `~n = 0b1101`, `~n + 1 = 0b1110` (-2)

***

通过这些公式和二进制示例，可以快速掌握位运算的核心操作逻辑。建议结合实践加深理解！
