# 子查询

| **子查询位置** | **作用** | **是否需要别名** | **别名加在哪里** |
| --- | --- | --- | --- |
| **WHERE / HAVING** | 提供筛选条件（值/列表） | **不需要/不允许** | 无 |
| **SELECT** | 提供一个计算出的列值 | **可选** | 加在 `)`<br> 后面，作为**列名** |
| **FROM / JOIN** | **充当一张临时表** | **必须强制!!!** | 加在 `)`<br> 后面，作为**表名** |
