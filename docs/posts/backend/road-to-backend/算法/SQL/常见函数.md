# 常见函数

在 LeetCode SQL 50 题以及实际面试中，你并不需要背下所有 MySQL 函数。重点掌握以下这几类**高频**函数就足够应对 90% 的题目了。

我为你整理了最实用的函数清单，按**功能**分类：

***

### 1. 日期与时间函数 (Date & Time)

*这是考频最高的一类，专门处理“第几天”、“某个月”等问题。*

| 函数 | 语法 | 说明 | 例子 |
| :--- | :--- | :--- | :--- |
| **DATEDIFF** | `DATEDIFF(日期1, 日期2)` | 计算 **日期1 - 日期2** 的天数差。 | `DATEDIFF('2023-01-05', '2023-01-01')` -> `4` |
| **DATE\_FORMAT** | `DATE_FORMAT(date, format)` | 将日期转为特定格式的字符串。**常用于按月分组**。 | `DATE_FORMAT('2023-01-15', '%Y-%m')` -> `'2023-01'` |
| **DATE\_ADD** | `DATE_ADD(date, INTERVAL 1 DAY)` | 日期加法 (也可以用 `DATE_SUB` 减法)。 | `DATE_ADD('2023-01-01', INTERVAL 1 MONTH)` |
| **YEAR / MONTH / DAY** | `YEAR(date)` | 提取年、月、日。 | `YEAR('2023-05-20')` -> `2023` |
| **IFNULL** | (放在这里特指日期) | 如果日期为空如何处理。 | 常见于 `LEFT JOIN` 后处理 NULL 日期。 |

***

### 2. 流程控制与空值处理 (Logic & Nulls)

*用来处理复杂的业务逻辑，比如“如果不为空则...否则...”*

| 函数 | 语法 | 说明 | 例子 |
| :--- | :--- | :--- | :--- |
| **IFNULL** | `IFNULL(val, default)` | 如果 `val` 是 NULL，返回 `default`，否则返回 `val`。 | `IFNULL(null, 0)` -> `0` (做平均售价那题时用过) |
| **COALESCE** | `COALESCE(v1, v2, v3...)` | 返回参数列表中**第一个不为 NULL** 的值（比 IFNULL 更强）。 | `COALESCE(null, null, 'A')` -> `'A'` |
| **IF** | `IF(条件, 真值, 假值)` | 简单的三元判断。 | `IF(x > 0, 'Positive', 'Negative')` |
| **CASE WHEN** | `CASE WHEN ... THEN ... END` | **SQL 中的 if-else 语句**，用于行列转换或复杂分类。 | `CASE WHEN price > 100 THEN 'High' ELSE 'Low' END` |

***

### 3. 字符串函数 (String)

*常用于修复名字格式、查找邮箱后缀等。*

| 函数 | 语法 | 说明 | 例子 |
| :--- | :--- | :--- | :--- |
| **CONCAT** | `CONCAT(str1, str2)` | 连接字符串。 | `CONCAT(first, ' ', last)` |
| **UPPER / LOWER** | `UPPER(str)` | 转大写/小写。 | `UPPER('abc')` -> `'ABC'` |
| **LEFT / RIGHT** | `LEFT(str, len)` | 从左/右截取 n 个字符。 | `LEFT('Apple', 1)` -> `'A'` |
| **SUBSTRING** | `SUBSTRING(str, pos, len)` | 从第 `pos` 位开始截取 `len` 个长度。 | `SUBSTRING('12345', 2, 3)` -> `'234'` |
| **LENGTH** | `LENGTH(str)` | 字符串长度 (字节)。还有 `CHAR_LENGTH` (字符数)。 | `LENGTH('Hi')` -> `2` |
| **GROUP\_CONCAT** | `GROUP_CONCAT(col)` | **将多行合并成一行字符串** (常用于展示某人买的所有产品)。 | 结果类似 `'Apple,Banana,Orange'` |

***

### 4. 数值函数 (Numeric)

*常用于计算百分比、四舍五入。*

| 函数 | 语法 | 说明 | 例子 |
| :--- | :--- | :--- | :--- |
| **ROUND** | `ROUND(num, decimals)` | 四舍五入保留几位小数。 | `ROUND(3.14159, 2)` -> `3.14` |
| **ABS** | `ABS(num)` | 绝对值 (计算距离时常用)。 | `ABS(-5)` -> `5` |
| **MOD** | `MOD(num, div)` | 取余数 (常用来判断奇偶)。 | `MOD(id, 2) = 1` (判断 id 为奇数) |

***

### 5. 窗口函数 (Window Functions) - **进阶必会**

*这是 LeetCode Medium/Hard 题目的神器，如果不掌握，很多题写起来会非常麻烦。*

| 函数 | 用途 | 常见场景 |
| :--- | :--- | :--- |
| **RANK()** | 排名 (1, 1, 3) | 允许并列，名次跳跃。 |
| **DENSE\_RANK()** | 排名 (1, 1, 2) | 允许并列，名次**不**跳跃 (求“第二高薪水”神器)。 |
| **ROW\_NUMBER()** | 排名 (1, 2, 3) | 强制不重复排名。 |
| **LAG() / LEAD()** | 找前一行/后一行数据 | 计算“连续登录”、“比昨天温度高”等问题。 |
