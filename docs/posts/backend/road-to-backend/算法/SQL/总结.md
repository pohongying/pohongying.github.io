# 总结

### 流程

1. 分析业务逻辑
2. 判断是否要goupby 分组（是否有聚合函数）
3. 判断表的连接形式
4. 根据查询字段，是否需要子查询等

### 注意事项

1. group by。如果查询字段没有用聚合函数，那么必须同时作为分组字段
2. if语句。常用与count，sum等聚合函数的场景
3. where和on。连接用on好可以保留null值，where则会过一整个行。尽量用on
4. having。如果你想用 `SUM()`、`COUNT()`、`AVG()` 这些聚合函数的结果作为筛选条件，你就必须用 `HAVIN`
5. 子查询。必须要有别名
6. <u>内连接。</u>**<u>层级关系</u>**<u>（父子、上下级、前后天）</u>
7. union。用于合并多个 SELECT 语句结果集的集合操作符，纵向合并

### 新NULL 值处理

* 可以使用聚合函数进行空值null值的转换，具体的聚合函数包括SUM/AVG/MAX/MIN
* 可以使用select语句进行转换，但空值应直接写在select中而非from中
* limit语句无法出现新的null值
* where和having同样无法出现新的null值
