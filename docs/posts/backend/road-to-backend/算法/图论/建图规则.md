# 建图规则

当然，以下是图论算法中有向图和无向图建图规则的简短总结：

### 有向图（Directed Graph）

* **定义**：每条边有一个明确的方向，从一个节点指向另一个节点。
* **建图规则**：
  * 对于每条边 `(x, y)`，仅添加一条从 `x` 到 `y` 的边。
  * 示例代码：

```java
List<Integer>[] g = new List[n];
Arrays.setAll(g, i -> new ArrayList<>());
for (int[] e : edges) {
    int x = e[0]; // 起点
    int y = e[1]; // 终点
    g[x].add(y); // 添加从 x 到 y 的边
}
```

### 无向图（Undirected Graph）

* **定义**：每条边没有方向，可以从任意一端到达另一端。
* **建图规则**：
  * 对于每条边 `(x, y)`，需要添加两条边：从 `x` 到 `y` 和从 `y` 到 `x`。
  * 示例代码：

```java
List<Integer>[] g = new List[n];
Arrays.setAll(g, i -> new ArrayList<>());
for (int[] conn : connections) {
    int x = conn[0];
    int y = conn[1];
    g[x].add(y); // 添加从 x 到 y 的边
    g[y].add(x); // 添加从 y 到 x 的边
}
```

### 总结

* **有向图**：单向边，只需添加一条边 `g[x].add(y)`。
* **无向图**：双向边，需添加两条边 `g[x].add(y)` 和 `g[y].add(x)`。

理解这些基本规则有助于正确构建不同类型的图，并应用于相应的图论算法。
