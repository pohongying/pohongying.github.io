# 连通

### 1. 图是连通的
+ **问题描述**: 如果题目明确说明图是连通的（即从任意一个节点可以访问到所有其他节点），那么只需要从一个节点开始进行深度优先搜索（DFS）或广度优先搜索（BFS）即可。
+ **示例**: 
    - “两个城市间路径的最小分数”（LeetCode 2492）：如果题目保证图是连通的，可以从节点0开始DFS，不需要遍历所有节点。

### 2. 图可能是不连通的
+ **问题描述**: 如果题目没有保证图是连通的，可能存在多个连通分量，则需要遍历所有节点以确保每个连通分量都被处理。
+ **示例**:
    - “岛屿数量”（LeetCode 200）：需要遍历整个二维网格中的每一个单元格，确保所有的岛屿都被计算到。
    - “省份数量”（LeetCode 547）：需要遍历每个人，确保所有的省份都被识别出来。

### 3. 需要找到全局最优解
+ **问题描述**: 如果问题要求找到全局最优解（如最小路径、最大值等），并且图可能包含多个连通分量，需要确保每个连通分量都被考虑。
+ **示例**:
    - “无向图中连通分量的数目”（LeetCode 323）：需要遍历所有节点，确保每个连通分量都被统计。

### 4. 特定起点的要求
+ **问题描述**: 如果问题要求从特定起点出发寻找某些属性（如最短路径），则只需从该起点开始进行搜索。
+ **示例**:
    - “单源最短路径”（Dijkstra算法、Bellman-Ford算法）：从指定的起点开始，计算到所有其他节点的最短路径。

### 总结
+ **连通图**: 只需从一个节点开始DFS/BFS。
+ **非连通图**: 需要遍历所有节点，确保每个连通分量都被处理。
+ **全局最优解**: 确保覆盖所有可能的情况，通常需要遍历所有节点。
+ **特定起点**: 仅从指定起点开始搜索。

通过理解这些问题的不同特性，可以选择合适的遍历策略来解决问题。
