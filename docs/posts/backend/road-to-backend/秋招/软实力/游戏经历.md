# 游戏经历

常泡在 RPG、MOBA、动作竞技类游戏里：《原神》玩了 800 多小时，全地图都探索遍了，还会研究 “圣遗物词条收益” 的逻辑；《英雄联盟》打了 1200 多小时，主打中单，最高打到峡谷之巅钻二，对英雄技能、装备体系门儿清；《永劫无间》有 600 多小时，三排打到陨星段位，清楚不同武器的数值特点，也爱和朋友讨论 “版本更新调整了啥机制”。虽然申的是后端岗，但这些经历让我更能理解游戏系统的逻辑和玩家想要啥

游戏经历

常玩《原神》（600 + 小时），关注资源投放与角色养成系统逻辑；《英雄联盟》（800 + 小时），研究对战匹配机制与数值平衡，能感知游戏服务端的核心需求。

自我评价

熟练 Java、SpringCloud 及 MySQL 优化，懂游戏服务端高并发、数据一致性痛点；学习能力强，能快速对接业务与技术落地，适配游戏开发节奏。
