# 兴趣爱好

代码对我来说不只是工作，更像是搭积木，我特别享受从零到一构建出一个系统的过程。

工作之外，我最常去的就是篮球场（或者足球场/羽毛球馆）。我喜欢那种和队友快速沟通、一个眼神就到位的感觉，这和在开发团队里高效协作，一起搞定一个复杂模块的体验很像，都特别有成就感。

偶尔也会去跑跑步、爬爬山，放空一下，也顺便锻炼下自己的韧性。毕竟解决一个顽固的Bug，和跑完最后五公里，有时候需要的是同一股劲儿。
