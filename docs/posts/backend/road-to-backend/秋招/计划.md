# 计划

***

### **核心指导思想 (The Philosophy)**

1. **主题驱动 (Theme-Driven):** 每天围绕一个核心技术主题进行“轰炸”，实现知识的深度内化。
2. **实践驱动 (Practice-Driven):** 项目不再是独立的任务，而是你验证和应用“八股文”知识的试验田。
3. **反馈闭环 (Feedback Loop):** 模拟面试是你一天学习成果的“验收环节”，通过录音复盘，找到问题，并在第二天进行修正。
4. **张弛有度 (Balance):** 高效学习不等于无休止地堆砌时间。科学的休息和周度规划，是保证你能坚持到最后拿到满意Offer的关键。

***

### **第一部分：Java后端核心知识复习大纲 (八股文系统化)**

这是我们接下来一个月的“弹药库”。我已经为你梳理好了最高频、最重要的知识模块。

| **模块** | **核心知识点** |
| :--- | :--- |
| **Java核心 (一): 集合** | `HashMap` (源码, put/get流程, 扩容机制, 红黑树转换), `ConcurrentHashMap` (1.7 vs 1.8, `CAS`, `synchronized`), `ArrayList` & `LinkedList` (区别, 扩容), `HashSet` (原理) |
| **Java核心 (二): 并发/JUC** | `synchronized` vs `ReentrantLock`, `volatile`, `ThreadLocal`, `AQS` (核心思想), **线程池** (7大参数, 工作流程, 拒绝策略, 核心线程数设置) |
| **Java核心 (三): JVM** | **JMM** (Java内存模型), **运行时数据区** (堆, 栈, 方法区), **垃圾回收** (GC Roots, 判断对象存活算法, G1/CMS收集器), 类加载机制 (双亲委派) |
| **数据库: MySQL** | **索引** (B+树, 聚簇/非聚簇索引, 索引失效场景), **事务** (ACID, 4大隔离级别), **MVCC** (多版本并发控制), **锁** (行锁, 表锁, 间隙锁, `悲观锁/乐观锁`) |
| **常用框架: Spring** | **IoC** (控制反转, DI), **AOP** (面向切面编程, 动态代理), `Bean`的生命周期, `@Autowired` vs `@Resource`, Spring事务传播机制 |
| **常用框架: Spring Boot** | **自动装配原理** (`@SpringBootApplication`注解, `@EnableAutoConfiguration`), `starters`, 核心配置文件`application.yml` |
| **中间件 (一): Redis** | 5种基本数据结构及应用场景, **RDB/AOF持久化**, **缓存三大问题** (穿透, 击穿, 雪崩)及其解决方案, 内存淘汰策略 |
| **中间件 (二): 消息队列** | Kafka/RocketMQ的基本架构, Producer/Consumer/Topic/Broker概念, **消息队列的应用场景** (解耦, 异步, 削峰填谷), 消息投递的可靠性保证 |
| **计算机网络** | TCP三次握手/四次挥手, TCP/UDP区别, HTTP/HTTPS区别 (SSL/TLS握手), 从输入URL到页面加载发生了什么 |
| **操作系统** | 进程与线程的区别与联系, 进程间通信方式, 死锁 |

### **第二部分：全新升级的每周学习计划 (周一至周日)**

我们将以“周”为单位推进，每天都有明确的主题。

#### **周一至周六：高强度作战日**

| 时间段 | 任务模块 | 核心目标与具体行动 |
| :--- | :--- | :--- |
| 9:00 - 11:00 | **算法专题训练** | **目标：** 掌握一类题型的核心思路。<br>**行动：**<br>1. **选题：** 根据**下方周度算法主题**，在 LeetCode Hot 100 中精选 3-4 道典型题。<br>2. **练习：** 独立思考15分钟，若无思路则看题解，重点是理解最优解的思路。<br>3. **编码：** 独立手写代码，提交并通过。 |
| 11:00 - 11:30 | **算法复盘总结** | **目标：** 将知识转化为自己的东西。<br>**行动：**<br>1. **总结思路：** 在笔记中用自己的话描述今天题型的通用解法/模板。<br>2. **归纳技巧：** 记录关键技巧（如：快慢指针、滑动窗口的左右边界如何移动）。<br>3. **标记错题：** 记录今天卡住的点或犯错的地方。 |
| 11:30 - 13:00 | **午休 & 碎片化投递** | **目标：** 恢复精力，见缝插针。<br>**行动：**<br>1. 彻底放松，吃饭，散步。<br>2. **利用饭后15分钟**，在招聘APP或官网上投递 5-10 家公司的简历。 |
| 13:00 - 15:00 | **项目驱动实践** | **目标：** 将理论知识落地，让简历上的项目“活起来”。<br>**行动：**（三选一，或根据自己项目情况调整）<br>1. **功能实现：** “为我的xx项目，用今天学的`Redis`实现排行榜功能。”<br>2. **性能优化：** “将项目中某个查询接口，通过添加`B+`树索引进行优化，并用`EXPLAIN`分析。”<br>3. **代码重构：** “将项目中发送邮件/短信的功能，重构为使用`RocketMQ`异步发送，提高API响应速度。” |
| 15:00 - 15:15 | **短暂休息** | 喝水，站起来走动，远眺。 |
| 15:15 - 17:15 | **八股文系统复习** | **目标：** 深度理解一个技术模块，为面试储备“弹药”。<br>**行动：**<br>1. 根据**下方周度八股文主题**，进行系统学习。<br>2. **不只是背：** 尝试画出原理图（如：HashMap结构、线程池工作流程）。<br>3. **关联项目：** 思考“这个技术点在我项目中是怎么用的？”或“可以怎么用？” |
| 17:15 - 18:30 | **晚餐 & 休息 & 海笔** | **目标：** 补充能量，完成在线笔试。<br>**行动：** 晚饭后如有企业笔试邀请，可在此时间段完成。 |
| 18:30 - 20:00 | **腾讯风格测评** | **目标：** 提升做题速度和准确率。<br>**行动：**<br>1. **18:30 - 19:20：** **行测专项训练。** 每天一个模块（图形推理、逻辑判断、言语理解、资料分析），计时练习。<br>2. **19:20 - 20:00：** **计算机基础选择题。** 刷牛客网等平台的Java/计网/OS/数据库选择题库。 |
| 20:00 - 21:45 | **知识深化/项目推进** | **目标：** 自由支配，查漏补缺或攻克难题。<br>**行动：**<br>1. 回顾今天没完全搞懂的“八股文”。<br>2. 继续下午未完成的项目开发任务。<br>3. 阅读优质技术博客，加深理解。 |
| 21:45 - 22:00 | **面试准备** | 准备好今晚模拟面试要讲的项目介绍、八股文主题和算法题。 |
| 22:00 - 23:00 | **结构化模拟面试** | **目标：** 锻炼表达能力，检验学习成果。<br>**行动：（全程录音！）**<br>1. **(5分钟) 自我介绍 + 项目介绍 (STAR法则):** 流利地介绍自己，并挑一个项目讲解其背景(Situation)、你的任务(Task)、你采取的行动(Action)和最终结果(Result)。<br>2. **(15分钟) 八股文追问:** 抽取今天复习的八股文模块，模拟面试官提问。“请讲讲`ConcurrentHashMap`在Java 1.8做了哪些优化？” “说说你对`MVCC`的理解。”<br>3. **(10分钟) 算法题讲解:** 拿出上午刷过的一道题，清晰地讲解你的解题思路、时间/空间复杂度分析。 |
| 23:00 - 23:30 | **录音复盘** | **目标：** 客观地发现自己的问题。<br>**行动：**<br>1. **回听录音：** 检查是否有口头禅、表达是否流利、逻辑是否清晰。<br>2. **技术复盘：** 检查技术点是否阐述准确，有没有说错或遗漏的地方。<br>3. **记录改进点：** 在笔记中记下明天需要改进的表达方式或技术知识点。 |
| 23:30 - 24:00 | **每日总结 & 计划微调** | 回顾今天完成情况，调整明日计划，安心睡觉。 |

#### **每日学习主题（示例第一周）**

| **星期** | **算法主题 (LeetCode Hot 100)** | **八股文主题** |
| :--- | :--- | :--- |
| **周一** | **数组与链表** (双指针, 快慢指针) | Java核心(一): 集合 |
| **周二** | **二叉树** (递归遍历, 层序遍历) | Java核心(二): 并发/JUC |
| **周三** | **动态规划 (入门)** (斐波那契, 路径问题) | Java核心(三): JVM |

| **周五** | **回溯算法** (组合, 排列) | 常用框架: Spring & Spring Boot |

#### **周日：总结与缓冲日**

周日是战略缓冲，不是完全放纵。

| 时间段 | 任务模块 | 核心目标与具体行动 |
| :--- | :--- | :--- |
| **上午** | **本周知识回顾** | 快速过一遍本周所有的算法题思路和“八股文”笔记，重点看标记的错题和疑难点。 |
| **下午** | **查漏补缺 / 兴趣拓展** | 针对回顾中发现的薄弱环节进行加固学习，或者看一些高质量的开源项目源码、技术分享视频。 |
| **晚上** | **彻底放松 & 制定下周计划** | 看电影、运动、和朋友聊天。在睡前花30分钟，规划好下一周每天的算法和八股文主题。 |

### **最后，作为面试官给你的几点忠告**

1. **“见题秒”的真谛：** 面试官考察算法，不是看你是否背下了原题，而是考察你分析问题、抽象建模、选择合适数据结构的能力。我们的目标是“见到同类型题，思路能秒出”，而不是背诵。
2. **项目是“锚点”：** 所有的“八股文”知识，如果不能和你做过的项目联系起来，就是空中楼阁。面试官最喜欢问：“你在项目中，哪里用到了多线程？”“你这个功能，为什么选择用Redis而不是直接查数据库？”时刻准备好用你的项目来印证你的技术深度。
3. **心态是基石：** 秋招是一场信息战和持久战。保持自信，接受暂时的挫折，坚持执行计划。你每天的努力，都会在收到Offer的那一刻得到回报。

这份计划的强度很大，但含金量极高。严格执行下来，一个月后，你的技术深度、广度以及面试表达能力，都将发生质的飞跃。

现在，开始行动吧！祝你秋招顺利，前程似锦！
