# 专业技能

+ 熟练掌握Java核心知识，熟悉常用集合及数据结构、面向对象、反射、异常、类加载等；
+ 熟练掌握MySQL，深刻理解事务及其原理、存储引擎、索引、锁机制、MVCC、各种日志等；
+ 熟练掌握Redis，深刻理解其数据结构、持久化策略、10模型、哨兵机制、高性能原理等；
+ 熟悉JUC并发编程，熟悉掌握各种锁机制、CAS、AQS、线程池、ThreadLocal等实现原理；
+ 熟练掌握JVM 内存结构、JMM、GC 算法、双亲委派机制、常见垃圾回收器等；
+ 熟练使用SSM、SpringBoot、 SpringCloud等框架，深刻理解IOC、AOP、Bean生命周期、循环依赖等；
+ 熟练使用消息中间件RabbitMQ，掌握消息队列模型、高效读写、刷盘机制、死信队列等知识；
+ 熟悉常见设计模式，如单例、工厂、模板方法、责任链、策略模式等；
