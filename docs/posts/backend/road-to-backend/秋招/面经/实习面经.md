8. ⚠️AI面试8道题会根据你的回答进行深挖，真的在模拟面试。现在的ai能力这么强的吗，面试这么高端，有一种高端的五花八门的痛苦

微信小程序北森闪面 一共8个题，每个题有30秒的思考时间，2分钟的答题时间（答题时需要录像） 每道题有3次答题重录机会。问题大概如下：

 1、自我介绍：姓名、年龄、学校、专业、项目（实习）经历、专业技能、性格、自我评价等 

2、描述自己的项目经历，做了哪些工作，达成什么成果？

 3、是否有调整自己工作方法的经历，怎么改变的，成效如何，举例说明

 4、在与团队合作时，是否与他人出现分歧和冲突，怎么解决的，效果如何，举例说明 

5、自己在项目或者合作中，遇到什么困难，如何解决的，效果如何，举例说明

 6、如果一天当中有多个任务或许项目，你是如何处理的，效果如何，举例说明

 7、自己有什么优点和优势，证明自己能胜任这个工作

 8、分享自己学习新知识、新技能的经历，如何学习的、效果如何。

### 盖娅互娱
#### 岗位性质
+ 游戏的后端维护
+ 主要用的PHP，go用的比较少
+ 要求待的时间长，因为前面熟悉业务和语言

#### 问的问题
+ http的了解？
+ redis的数据类型的了解？
    - 搞混淆了，sorted_set有序集合
    - hash存对象的热key问题
    - List其实很常用
    - Redis主要用于存比较频繁的数据，我没打到点子上
+ MySQL的存储引擎的异同？
    - 我回答：有事务和没事务，又编了一个，让我不会直接说不懂
+ vue的好处？
    - 我：方便，有很多组件，但是语言组织的不太好
+ session和cookie的区别？为什么要有cookie和session?
    - 一个在客户端，一个在服务端，两者是相互依存的
    - 面试官：没回答到点子上，可以没有cookie和session
    - 我回答的很乱，没回答到关键点：http是无状态的
+ 谈一下websocket的理解？websocket的用法？
    - 服务器可以给客户端发送消息，不是长轮询和短轮询
    - 用于通讯，和视频？，没有视频
+ 为什么要优化RPC框架？
    - 我：之前的都是客户端代理，加服务器的服务选择，使用zk和netty

#### 项目如何
+ 十多个项目，很杂
+ 用的PHP
+ 学的东西很多
+ 语言不重要

#### 总结
+ 这次面试被好好拷打了一遍，基础确确实实不牢，要真正去理解它，是什么、为什么、怎么样，切勿死记硬背。
+ 这段时间，先好好沉淀吧，冲击明年2-3月份的暑期实习，只要有机会，就能放弃呀！
+ 不想去了，因为我明年还要找呢，到时候啥也没学到就走了，PHP也不好找工作。
