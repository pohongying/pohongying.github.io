# 索引下推

当一个查询使用了多列的联合索引，但 `WHERE` 条件中，一部分可以用于索引的范围定位，而另一部分无法用于定位、只能用于过滤时，ICP 就能发挥巨大作用。

可以直接在存储层的索引树上直接筛选，而不是回表到server层，然后再进行筛选
