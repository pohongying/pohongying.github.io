# Redisson

# 看门狗机制
**是什么**

watch dog是redssion 在使用分布式锁时的自动续约的机制。相当于，每个月我们充vip会员，会给自动续费，避免你的服务用不了。当然，watch dog并不会真的等到快过期了才续期，它通常会在三分之一周期的时候续期

**为什么**

分布式锁，一般有几个特点：互斥、可重入、性能。关键是互斥，单体的话我们可以使用reentrantlock，sysconized实现悲观锁。在分布式环境下，不能一直阻塞下去，要合理设置过期时间，太长了会导致性能下降；太短了，一个任务还没执行完，另外一个任务就进来了，会修改共享变量，导致并发问题。因此，必须要根据实际的情况，来动态调整过期时间

**怎么样**

默认过期时间是30s，续期时间为它的3分之一，也就是10s。原理是通过一个定时任务，通过netty，隔一段时间执行lua脚本，实现锁的续期。当执行完之后，进行解锁操作，因为Redisson 是在jvm中运行的，也就是说如果服务挂了，并没有解锁了，那么也不会续期，直接等待过期时间，自动解锁即可。

解锁失败，也会取消续期命令
